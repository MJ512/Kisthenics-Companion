# Windows Deployment & Packaging Guide

This document describes building, packaging, and distributing **Kisthenics Desktop Companion** on Microsoft Windows (Windows 10 & 11, x64).

---

## 1. Distribution Targets

Tauri bundles two standard Windows installer formats:

1. **NSIS Installer (`.exe`)**:
   - Fast, self-contained executable installer generated via `makensis`.
   - Default install mode: `currentUser` (requires no administrative UAC elevation, avoiding permission barriers for standard user accounts).
   - Artifact location: `src-tauri/target/release/bundle/nsis/Kisthenics Desktop Companion_<version>_x64-setup.exe`.
2. **WiX / MSI Installer (`.msi`)**:
   - Enterprise-friendly Windows Installer package built using WiX Toolset (`candle` and `light`).
   - Artifact location: `src-tauri/target/release/bundle/msi/Kisthenics Desktop Companion_<version>_x64_en-US.msi`.

---

## 2. Windows Security & Trust

### Crucial Principle: Never Compromise User Security
End users must **never** be instructed to disable security mechanisms:
- ❌ Do **not** advise disabling Windows Defender.
- ❌ Do **not** advise disabling Smart App Control.
- ❌ Do **not** advise disabling Windows SmartScreen.
- ❌ Do **not** modify system security policies during installation.

The desktop client must follow standard, legitimate Windows application packaging standards.

### Distinguishing Dev-Machine Policy vs. End-User Distribution
- **Development Policy (Build Machine)**: Windows Smart App Control in "Evaluation" or "Enforced" mode may occasionally block freshly compiled, unsigned build-script executables (`build-script-build.exe`) generated by Cargo during local compilation. This is strictly a local developer workstation phenomenon.
- **End-User Distribution**: End-user installations are governed by code signing reputation. Once packaged and digitally signed with an Authenticode certificate, the installer runs normally on consumer systems.

## 3. Code Signing for Production

To prevent SmartScreen warnings on download and establish application identity, production binaries must be signed with a valid Microsoft Authenticode code signing certificate (EV or standard OV).

### Signing via `signtool.exe`
```powershell
signtool.exe sign `
  /tr http://timestamp.digicert.com `
  /td sha256 `
  /fd sha256 `
  /sha1 <CERTIFICATE_THUMBPRINT> `
  "path\to\Kisthenics Desktop Companion_1.0.0_x64-setup.exe"
```

### Tauri Automated Signing
Configure certificate thumbprint or environment variables in your secure CI/CD runner:
- `TAURI_SIGNING_PRIVATE_KEY`
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
